📖 使用说明

基本使用流程：
1. 设置 尺寸公差 和 重量公差，例如 5 表示 ±5%。
2. 将资料原文粘贴到“数据输入”区域，每行一个产品。程序会保留每行 原始资料，计算和推断不会改写原始资料字符串。
3. 如资料存在缺失，可按需要开启 推断开关；关闭时仅使用资料中已提供的数值，缺失项保持缺失。
4. 点击 🚀 开始计算，或使用 Ctrl+Enter 快速计算。已提供的尺寸/重量会正常计算公差范围；启用推断后，可推断的缺失项会先生成工具计算值，再计算对应公差。
5. 查看公差范围、原始资料缺失、仍缺失、质量警告、解析异常和推断来源。紫色推断标签表示该值由工具计算得到，不属于原始资料。
6. 如需临时调整当前计算结果，可点击 ✏️ 修改；该操作只修改当前工具中的计算值，不会改写“原始”一栏保存的资料文本。
7. 计算完成后，可导出 CSV、JSON，也可点击 🧩 生成执行脚本。

推断模式：
• 智能分组：逐字段按“同名称 → 同类型 → 全局尺寸比例”依次尝试补全；同名称/同类型可用于长度、宽度、高度和重量，全局比例只用于尺寸。
• 仅同名称：只使用名称完全一致的其他资料记录均值补全缺失字段。
• 仅全局比例：忽略名称和类型，只根据完整尺寸样本的整体长宽/长高比例推算缺失尺寸；不会通过全局比例推断重量。

填充脚本使用：
先选择正确的 KeyCode 和 脚本模式 → 生成脚本 → 复制代码 → 打开目标网页 → 按 F12 打开浏览器控制台 → 粘贴并运行 → 浏览器选择本工具导出的 JSON 文件。脚本会自动定位 Measurement Chart、自动增加不足的行、按字段名精确填充，并将 Samples #6–#13 填为 --。

注意事项：
• 原始资料有 ?、null、n/a 等缺失内容时，程序会保留缺失位置，不会把后面的尺寸向前错位。
• 紫色“推断”标签表示该数值并非原始输入，请重点核对后再用于后续操作。
• 资料缺失只表示原始资料中存在空缺，不等同于质量异常；质量警告仅用于尺寸比例、尺寸/重量过大等数值合理性提醒；解析异常表示产品已建立但某字段未能可靠解析；解析失败表示整行无法建立有效产品记录。
• 输入内容和设置会在停止输入后自动保存到当前浏览器本地；输入框会自动增高，达到最大高度后改为内部滚动。
• 本工具用于辅助整理和计算；正式生产或质检仍应以原始资料及实际测量要求为准。

📝 数据输入

支持格式（每行一个产品）：
Fire Truck: 7.6 x 2.7 x 4.1cm; 31.6g（尺寸 + 分号 + 重量）
Police Car,7.2,2.8,2.9,26.6（CSV：名称,长度,宽度,高度,重量）
Tow Truck: 6.7 x ? x 3cm; ?g（保留缺失位置）
Ambulance: length 8.5 width 3.2 height 4.0 weight 55g（英文字段名）
救护车: 长度 8.5cm 宽度 3.2cm 高度 4cm 重量 55g（中文字段名）
挖掘机 15.5cm x 8cm x 12cm 120g（无分号，末尾直接跟重量）
Mixed: 12inch x 5cm x 40mm; 0.12kg（各尺寸可使用不同单位）
尺寸顺序：未使用字段名时，前三个尺寸槽位固定按“长度 × 宽度 × 高度”解释；缺失槽位不会被后面的数值顶替。
支持尺寸单位：mm / cm / m / inch / in / 英寸符号 " / 英尺符号 '（自动换算为 cm）
支持重量单位：mg / g / kg / oz / lb（自动换算为 g）
缺失标记：?、*、null、none、n/a、na、-、—、~、留空等；建议优先使用 ?，最清晰且不容易与尺寸分隔符混淆。
单位说明：同一条资料中每个尺寸会独立识别单位，例如 12inch x 5cm x 40mm 可正确分别换算。
